# BB&D+E Oscars — Entries Pages

This bundle contains:
- `index.with-pills.html` — a minimal index showing the **My Entries** pill bar. You can copy the pill bar into your full leaderboard index.
- `entries/NAME.html` — one page per contestant, single-file. Each page fetches the published CSV and shows ✅/❌ per category.
